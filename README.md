# btw-emerald-tools
Emerald Tools does exactly what you think, and adds a new emerald alloy and emerald tools, which serve as a sidegrade after unlocking the Crucible. You can alloy emerald ingots using one gold ingot and two emeralds, and this alloy can be decrafted via a Stoked Cauldron (albeit at a 2/3rd loss of gold)

How do emerald tools stack up against iron and diamond?
* Emerald tools are the same durability as iron
* Emerald tools are nearly as fast as gold and SFS; faster than iron and diamond
* Emerald tools have the enchantability of gold

Emerald tools are also now included in priest enchant trades, and a new achievement has been introduced. This was a fun little addon I made in a few hours, with a basic integration idea. Enjoy!
